# Big Fish Advisor 1.0.0

A cute big-fish assistant mod for **Slay the Spire** with Chinese advice for:

- route planning and boss/elite scouting
- card reward pick/skip and archetype commitment
- combat card/target order, enemy patterns and relic counters
- Neow and every event option
- campfire, shop, potion sequencing and card selection
- boss relic choice and relic/deck synergy

## Install

1. Install **ModTheSpire** and **BaseMod** for Slay the Spire.
2. Download `BigFishAdvisor-1.0.0.zip` below.
3. Extract it into the game directory and run `install.ps1`.
4. Choose **Play with Mods** in Steam.

The installer backs up the Workshop-only `mts-launcher.jar` as `mts-launcher-original.jar` and installs a local launcher so Play with Mods works without the Workshop item.
